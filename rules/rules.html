这份文件只给写内容和 AI 看，不参与游戏页面。真正生效的样式在 skill.html。下面每条都是「标签长什么样，颜色是哪一个」。

属性

生命值 的颜色是 #ff6b78。写生命值时用它。

饥饿值 的颜色是 #c49212。写饥饿值时用它。

理智值 的颜色是 #c65a12。写理智值时用它。不要再写精神值。

潮湿度 的颜色是 #3ec4e0。潮湿度、潮湿值都用它。

变身值 的颜色是 #8ed34a。伍迪变身值用它。

伤害 的颜色是 #5d7084，与阿比盖尔攻击力圆圈相同。写伤害、威力时用它，数字仍放在 b 里，例如 5点伤害。范围伤害、爆炸伤害、位面伤害里的「伤害」也包进去。技能名「威力武器」里的威力同样包进去。

力量值 用已有的青色标签，颜色是 #4dffea。属性栏圆圈底色与这个标签相同，沃尔夫冈的圆圈里是肌肉。

激励值 的颜色是 #c084fc，浅紫。属性栏圆圈底色与这个标签相同，薇格弗德的圆圈里是高音谱号。

强调

数字 的颜色是 #7fd4ff。点数、百分比、倍数、时间、距离、个数都放进 b，例如 8点、25%、3.75个地皮、3天、×1。

公式整段放进 b，里面有中文也一起放进去。括号里是一整条公式时，去掉括号，改用 b。括号只是公式里面的运算优先级时，括号留着，整段公式再套 b。例如 22-2×周围人数，以及 20×(总数/阈值)。

警告 的颜色是 #ff3d2a。需要读者特别注意、容易理解错的句子用它。

技能名 的颜色是 #7dce7a。点名某个技能时用它。

按键 的颜色是 #b7c4d0，灰里带一点蓝。用来写键盘和鼠标按键，例如 <keyboard>Alt</keyboard>。

结构和跳转

人物 的颜色是 #d7a6ff，带下划线。点了会跳到同名角色。写法是 <character>沃特</character>。显示名和角色名不同时，写成 <character name="薇诺娜">女工</character>。

roles 不是 character。阿比盖尔这类多形态写 <roles><role1>…</role1><role2>…</role2><role3>…</role3></roles>，每个形态里用 h3 当切换按钮的名字。

补充说明 是金色虚线下划线。悬停或点按后弹出 text。text 里要换行就写 \n。弹出的框和正文用同一套标签，所以可以写 <character>沃利</character>，点名字会跳到该角色。例如 <notice text="只能由<character>沃利</character>制作">鲜果可丽饼</notice>。属性栏里的生命值、饥饿值、理智值、力量值、激励值也可以这样写，例如 <notice text="技能可提升上限">100</notice>。

段落用 p，小节标题用 h3，更小的标题用 h4，列表用 ul 和 li，可折叠内容用 details 和 summary，对照表用 table。表比画面宽时可以左右滑动，手机上用手指横着拉，不用改格子。

专属物品分段用 <br>，不要靠源码里的换行。

技能组的 note、tip，以及角色页底部的总结，和正文用同一套标签。锁节点上的 tip 保持纯文字，那些句子要拿来判断能不能解锁。

配方

专属物品的 recipe 写成：材料×数量 + 材料×数量 → 数量 产物。例如 可靠的胶布×1 + 金子×2 + 萤火虫×1 → 1 薇诺娜的聚光灯。配方里的生命值、饥饿值、饱食度、理智值、潮湿度、潮湿值、变身值、伤害、威力用对应标签。配方里的数字保持原样，不要套 b。例如 -50<health>生命值</health>。技能树配方同样可以写这些标签。

专属物品和制作物品的 name 可以写 notice。例如 <notice text="右键打开储物空间">魔术师高礼帽</notice>。

技能树 recipes 里的产物要用 item 包起来，才会出现下划线并打开对应物品：1 纯粹辉煌 + 3 哀悼荣耀 → 1 <item>亮泽之怒</item>。物品对象的 id 是「技能 id_序号」，放在 craftItems 里。
