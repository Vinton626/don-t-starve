这份文件只给写内容和 AI 看，不参与游戏页面。真正生效的样式在 css/common-tags.css；度名清单在 js/foodfarm/common.js 的 FOOD_DEGREES。

与 skillrules 独立：紫色、绿色、粉色等可以和技能树标签同色，不要求区分。只需避开全局规则 commonrules.html 里的色（三维、潮湿、伤害、b、warn、keyboard、notice 等）。本文件内部：各「度」之间、以及度与肥料之间，仍要可区分。

烹饪度颜色

基础食物的 degrees 键与标签同名。数字仍放在 b 里，文字用对应度标签。完整清单仅以下这些，不要再加。

肉度 键 meat，#c2185b。

蔬菜度 键 veg，#7dce7a。不要写成 veggie（veggie 是食用类型「素食」）。

水果度 键 fruit，#ff9b9b。

鱼度 键 fish，#6d93ad。

蛋度 键 egg，#e8c4a8。

甜味剂度 键 sweetener，#ffb6c1。

怪物度 键 monster，#c084fc。

乳制品度 键 dairy，#cfc8b4。

冰度 键 ice，#8ec8f0。

不可食用度 键 inedible，#9a9a9a。

魔法度 键 magic，#9b6bff。

油脂度 键 fat，#e6b85c。

种子度 键 seed，#a3c96b。与食用类型 seeds 不同。

装饰度 键 decoration，#d4a0c8。

干货度 键 dried，#b08968。

预处理度 键 precook，#7eb8a8。

例如 1蔬菜度、1.5水果度。

肥料颜色（种植）

与沃姆伍德正文里粪肥 / 堆肥 / 催长剂同色。人物页继续可用原标签；种植 / farm 正文优先用语义标签。

粪肥 的颜色是 #d4925a，与 brown 相同。标签 <manure>，数据键 manure。沃姆伍德写法：<brown>粪肥</brown>。

堆肥 的颜色是 #c5c5c5，与 grey 相同。标签 <compost>，数据键 compost。沃姆伍德写法：<grey>堆肥</grey>。

催长剂 的颜色是 #b3e5ff，与 lightblue 相同。标签 <formula>，数据键 formula。沃姆伍德写法：<lightblue>催长剂</lightblue>。

种子 fertilizer 直接写每阶段三肥净值，键是 manure / compost / formula：负数=消耗，正数=产出，0 可省略或写 0。例如土豆：{"formula":-4,"compost":2,"manure":2}。

三肥圆圈 + 耗水/阶段

种植篇卡片与种子弹窗用四维圆圈：前三个是每阶段三肥净值（产出 − 消耗），第四个是耗水/阶段。悬停写「催长剂/阶段」「堆肥/阶段」「粪肥/阶段」。写法同 commonrules 的 state。

stat-formula 催长剂（🧪，底色 #3d7fa6）、stat-compost 堆肥（🍂，底色 #6e6e6e）、stat-manure 粪肥（💩，底色 #8a5a2e）。肥料数值放在 b 里，正数带 +，例如 +2、-4。

stat-water 耗水/阶段（💧，底色 #2a6f9e）。文案写「耗水/阶段」，不要写「潮湿值」。数据里写百分比数值（如 0.75 表示 0.75%），页面展示时加 %。例如 <notice text="耗水/阶段"><b>0.75%</b></notice>。

耗水/阶段不参与三肥配比运算，只在页面展示。

生成肥料圆：CommonTags.stateOrbHTML("formula", "<b>-4</b>")；水：CommonTags.stateOrbHTML("water", "…")。

食用类型（foodtype）

普通食物本体、烤 cooked、晾 dried、种子 seed、料理都可写，对应谁能吃。和烹饪「度」无关。不要再用 secondaryfoodtype。

写法：

只有一种：写 foodtype，例如 "foodtype":"veggie"。

多种：写 foodtype + foodtype2 + foodtype3… 有几种写几个。例如浆果 "foodtype":"veggie","foodtype2":"berry"；怪物肉 "foodtype":"meat","foodtype2":"monster"。

也可以从 foodtype1 起笔：必须同时有 foodtype2（只写 1 不合法）。之后同样 foodtype3…

完整键与中文（仅这些）：

veggie 素食、generic 通用、meat 肉、elemental 元素、gears 齿轮、horrible 可怕、insect 昆虫、seeds 种子、berry 浆果、raw 生的、burnt 烧焦的、nitre 硝石、roughage 粗食、wood 木制、goodies 好东西、monster 怪物、moonshard 月亮碎片、miasma 瘴气。

清单在 js/foodfarm/common.js 的 FOOD_TYPES。展示用 Foodfarm.foodTypeText(entry)。

保质期

普通食物、烤/晾、种子、料理都可写 spoilDays。数字是天数，详情显示为「保质期：N 天」。不会腐烂写 "spoilDays": "永久"，页面只显示「永久」，不加「天」。没有、或写 null，就省略这一行。

料理的 cookSeconds、priority 还没定稿时写 "待补充"。详情只显示「待补充」：烹饪时间后面不加「秒」。判定时这个优先级按 0 和其他料理比较。must 的 op 按原样显示，"=" 表示该食材格数必须正好等于 value。

基础食物字段

hide：布尔。为 true 时不出现在普通食物图鉴卡片里，但仍可作为料理篇锅原料（噩梦燃料、树枝这类非食用原料用它）。默认 / 省略视为 false。

plantOnly：布尔。为 true 时只留种植记录，不进食物图鉴，也不进烹饪锅。针刺旋花用它，并同时写 hide: true。

cooked：烤熟形态子对象，可选。只有写了才参与切换。

dried：晾干形态子对象，可选（肉、海带等才有）。只有写了才参与切换；多数食物不必写这个字段。

图鉴卡片右上角按已有字段各放一个按钮，晾在烤左边。点「晾」或「烤」切到该形态，再点同一个按钮回到生。只有其中一个字段就只显示对应按钮。两个字段都没有则缩小显示 *，悬停提示「不可烤不可晾」。

烤/晾子对象常用字段：id / name / health / hunger / sanity / spoilDays / foodtype（及 foodtype2…）/ degrees。

种子字段

seed.foodtype（及 foodtype2…）：种子自身的食用类型，常见 seeds。写法同普通食物。

seed.spoilDays：种子保质期（天）。没有就省略。

seed.hate_season：不喜欢的季节数组，取值 spring / summer / autumn / winter。不在数组里的季节都算合适。没有就写 []。

seed.water：耗水/阶段，百分比数值（如 0.75 = 0.75%）。种植卡片第四维展示时带 %；不参与配比。没有可省略。

seed.desc：简短描述，可用正文标签；没有就写空字符串。

seed 可以写成完整对象，也可以写成另一条食物的 id，多种植株共用同一颗种子时用 id。例如必忘我和后面的杂草都写 "seed": "seeds"，种子本体只写一次，并带上它自己的 cooked、degrees。每株不一样的肥、水、季节不要写进种子，写在植株的 grow 里，种植篇会叠到这颗种子上。

嵌在植株里的种子也会出现在普通食物图鉴，按名字或 id 搜索。同一种子只出现一张卡片。

料理详情里的配方举例

不枚举全部可行组合（组合数会爆炸）。详情底部「可实现举例」每次随机给出至多两条不同的 4 格配方。必用原料按名字放入；每种度要求在不触犯 limit 的食材里随机挑选，有纯单度食材时优先用纯单度。需求和必用都满足以后，random 为 true 时，剩下的空格从所有不在 limit 里的纯单度食材中再随机配；否则空格只继续使用已经要求的度。凑满后用烹饪判定校验，只有真正会做出这道菜的配方才展示。
