这份文件只给写内容和 AI 看，不参与游戏页面。真正生效的样式在 css/common-tags.css；度名清单在 js/foodfarm/common.js 的 FOOD_DEGREES。

与 skillrules 独立：紫色、绿色、粉色等可以和技能树标签同色，不要求区分。只需避开全局规则 commonrules.html 里的色（三维、潮湿、伤害、b、warn、keyboard、notice 等）。本文件内部：各「度」之间、以及度与肥料之间，仍要可区分。

烹饪度颜色

基础食物的 degrees 键与标签同名。数字仍放在 b 里，文字用对应度标签。

肉度 的颜色是 #c2185b，洋红色。标签 <meat>，键 meat。

菜度 的颜色是 #7dce7a，绿色。标签 <veg>，键 veg。

水果度 的颜色是 #ff9b9b，浅红色。标签 <fruit>，键 fruit。

鱼度 的颜色是 #6d93ad，灰蓝色。标签 <fish>，键 fish。与全局 damage 灰不同，偏蓝。

蛋度 的颜色是 #e8c4a8，肉色。标签 <egg>，键 egg。比本文件里的粪肥棕更浅、更粉。

甜味剂度 的颜色是 #ffb6c1，粉色。标签 <sweetener>，键 sweetener。与全局物理伤害粉（#ffd0f8）不同，更深一点。

怪物度 的颜色是 #c084fc，紫色。标签 <monster>，键 monster。

乳制品度 的颜色是 #cfc8b4，米白偏灰。标签 <dairy>，键 dairy。纯白在深色背景上看不清，略压暗。

冰度 的颜色是 #8ec8f0，浅蓝色。标签 <ice>，键 ice。比本文件催长剂 / lightblue（#b3e5ff）更深，也避开全局位面浅蓝与潮湿度海蓝。

不可食用度 的颜色是 #9a9a9a，灰色。标签 <inedible>，键 inedible。比本文件堆肥灰（#c5c5c5）更深一档。

例如 1菜度、1.5水果度。

肥料颜色（种植）

与沃姆伍德正文里粪肥 / 堆肥 / 催长剂同色。人物页继续可用原标签；种植 / farm 正文优先用语义标签。

粪肥 的颜色是 #d4925a，与 brown 相同。标签 <manure>，数据键 manure。沃姆伍德写法：<brown>粪肥</brown>。

堆肥 的颜色是 #c5c5c5，与 grey 相同。标签 <compost>，数据键 compost。沃姆伍德写法：<grey>堆肥</grey>。

催长剂 的颜色是 #b3e5ff，与 lightblue 相同。标签 <formula>，数据键 formula。沃姆伍德写法：<lightblue>催长剂</lightblue>。

种子 fertilizer 直接写三肥净值，键是 manure / compost / formula：负数=消耗，正数=产出，0 可省略或写 0。例如土豆：{"formula":-4,"compost":2,"manure":2}。

三肥圆圈 + 耗水/阶段

种植篇卡片与种子弹窗用四维圆圈：前三个是三肥净值（产出 − 消耗），第四个是耗水/阶段。写法同 commonrules 的 state。

stat-formula 催长剂（🧪，底色 #3d7fa6）、stat-compost 堆肥（🍂，底色 #6e6e6e）、stat-manure 粪肥（💩，底色 #8a5a2e）。肥料数值放在 b 里，正数带 +，例如 +2、-4。

stat-water 耗水/阶段（💧，底色 #2a6f9e）。文案写「耗水/阶段」，不要写「潮湿值」。数值用 notice 注明含义，例如 <notice text="耗水/阶段"><b>2</b></notice>。

耗水/阶段不参与三肥配比运算，只在页面展示。

生成肥料圆：CommonTags.stateOrbHTML("formula", "<b>-4</b>")；水：CommonTags.stateOrbHTML("water", "…")。

食用类型（foodtype）

基础食物与料理都要写，对应游戏里谁能吃这类东西。和烹饪「度」无关。

字段：

foodtype：主类型，字符串键。

secondaryfoodtype：次类型，可选；没有就写 ""。游戏里浆果是 veggie+berry、怪物肉是 meat+monster 时用它。

常用键与中文：

veggie 素食、meat 肉食、goodies 好东西、generic 通用、seeds 种子、berry 浆果、monster 怪物、horrible 可怕、roughage 饲料、elemental 元素、gears 齿轮、wood 木头、raw 生食、burnt 烧焦、insect 昆虫。

清单在 js/foodfarm/common.js 的 FOOD_TYPES。展示用 Foodfarm.foodTypeText(entry)。

基础食物字段

hide：布尔。为 true 时不出现在普通食物图鉴卡片里，但仍可作为料理篇锅原料（噩梦燃料、树枝这类非食用原料用它）。默认 / 省略视为 false。

cooked：烤熟形态子对象，可选。只有写了才参与切换。

dried：晾干形态子对象，可选（肉、海带等才有）。只有写了才参与切换；多数食物不必写这个字段。

图鉴卡片右上角一个按钮，在已有形态之间循环，按钮文案是下一个形态：生 / 烤 / 晾。例如肉有烤+晾：生时显示「烤」→烤时「晾」→晾时「生」。只有烤：烤 ↔ 生。两个字段都没有则缩小显示 *，悬停提示「不可烤不可晾」。

子对象常用字段：id / name / health / hunger / sanity / foodtype / secondaryfoodtype / degrees。

种子字段

seed.hate_season：不喜欢的季节数组，取值 spring / summer / autumn / winter。不在数组里的季节都算合适。没有就写 []。

seed.water：耗水/阶段，数字。种植卡片第四维展示用；不参与配比。没有可省略。

seed.desc：简短描述，可用正文标签；没有就写空字符串。

种子自身的 health / hunger / sanity 是吃种子的三维，弹窗第三行显示。

料理详情里的配方举例

不枚举全部可行组合（组合数会爆炸）。详情底部「可实现举例」只用：必用原料 + 每种所需度的第一个纯单度食材（degrees 里只有一种度）+ 纯单度填充凑满 4 格。双度食材（如榴莲：水果+怪物）不拿来当度的代表例。
