这份文件是全局规则，技能树、料理与种植等模块共用。只给写内容和 AI 看，不参与游戏页面。

烹饪度与肥料专属颜色见 foodfarmrules.html。

对应运行时逻辑在 js/common/tags.js（挂到 window.CommonTags，也支持 CommonJS / AMD）。样式在 css/common-tags.css。

页面引用示例：先加载 ../js/common/tags.js，再 CommonTags.bind(root)；需要 notice 气泡时再 CommonTags.installNoticeTips({ tipId: "notice-tip" })。生成三维圆圈可用 CommonTags.stateOrbHTML("health", "<b>150</b>") / CommonTags.statesHTML([...])。配方等需保留标签的转义用 CommonTags.escapeKeepingTags(text)。

三维颜色

角色、基础食物、料理共用同一套三维标签。数字仍放在 b 里，文字用下面的标签。

生命值 的颜色是 #ff6b78。写生命值时用它。如果出现为生命值上限，则需要将上限两个字包进去。

饥饿值 的颜色是 #c49212。写饥饿值时用它。

理智值 的颜色是 #c65a12。写理智值时用它。不要再写精神值。

例如 +60生命值、+150饥饿值、+15理智值。

潮湿度与伤害

潮湿度 的颜色是 #3ec4e0。潮湿度、潮湿值都用它。

伤害 的颜色是 #5d7084，与攻击力圆圈相同。写伤害、威力时用它，数字仍放在 b 里，例如 5点伤害。范围伤害、爆炸伤害里的「伤害」也包进去。技能名「威力武器」里的威力同样包进去。

物理伤害 的颜色是 #ffd0f8，浅粉，偏白。四个字整段放进这个标签，不要再写成 物理<damage>伤害</damage>。

位面伤害 位面防御 的颜色是 #bbf0fc，浅蓝，偏白。四个字整段放进这个标签，不要再写成 位面<damage>伤害</damage>。

强调：b / warn / keyboard

数字 的颜色是 #7fd4ff。特殊：(数字)技能名的这种特殊情况，不要套 b。点数、百分比、倍数、时间、距离、个数都放进 b，例如 8点、25%、3.75个地皮、3天、×1。地皮相关：距离时「个」是单位、「地皮」是名词，写成 3.75个地皮（地皮不进 b）；速率时「个地皮/秒」才是单位，写成 7.5个地皮/秒（整段进 b）。不要写成每秒2个地皮，应改成 2个地皮/秒。

公式整段放进 b，里面有中文也一起放进去。括号里是一整条公式时，去掉括号，改用 b。括号只是公式里面的运算优先级时，括号留着，整段公式再套 b。例如 22-2×周围人数，以及 20×(总数/阈值)。

警告 的颜色是 #ff3d2a。需要读者特别注意、容易理解错的句子用它。

按键 的颜色是 #b7c4d0，灰里带一点蓝。用来写键盘和鼠标按键，例如 <keyboard>Alt</keyboard>。

notice 补充说明

补充说明 是金色虚线下划线。悬停或点按后弹出 text。text 里要换行就写 \n。弹出的框和正文用同一套标签，所以可以写 <character>沃利</character>，点名字会跳到该角色。例如 <notice text="只能由<character>沃利</character>制作">鲜果可丽饼</notice>。属性栏里的生命值、饥饿值、理智值、力量值、激励值也可以这样写，例如 <notice text="技能可提升上限">100</notice>。

专属物品和制作物品的 name 也可以写 notice。例如 <notice text="右键打开储物空间">魔术师高礼帽</notice>。

运行时：页面放一个 <div id="notice-tip" class="notice-tip tag-text" hidden></div>，并调用 CommonTags.installNoticeTips({ tipId: "notice-tip" })。

角色三维表示（states / state）

人物、普通食物图鉴、料理篇、怪物图鉴等凡是用圆圈展示三维的地方，一律用同一套 states / state 与 emoji，不要另写一套图标。

在人物特性、随从介绍等正文里，要用圆圈+数值展示三维（或攻击力等）时，用 states / state，不要只写纯文字「生命值 xxx」。

食物 / 怪物卡片与弹窗：名称 + 生命 / 饥饿 / 理智三个圆圈（❤️ / 🍗 / 🧠），数值放在 b 里。生成可用 CommonTags.statesHTML([{ kind: "health", valueHTML: "<b>8</b>" }, …])。

多个圆圈并排：外包一层 <states>…</states>，里面每个属性一个 <state>…</state>。

只有一个圆圈时，可以单独写 <state>…</state>，不必再套 states。

每个 state 内部固定两段：

1. 圆圈：<span class="stat-orb stat-health"><span class="stat-emoji">❤️</span></span>

2. 数值：<span class="stat-value">…</span>，数字用 b；需要补充说明时可用 notice。

圆圈底色 class 与含义：

stat-health 生命（❤️，底色 #8f1d28）

stat-hunger 饥饿（🍗，底色 #c49212）

stat-sanity 理智（🧠，底色 #c65a12）

stat-attack 攻击 / 伤害圆圈（⚔️，底色 #5d7084，与 damage 同色系）

种植用的三肥圆圈（stat-formula / stat-compost / stat-manure）与第四维耗水/阶段（stat-water，💧）见 foodfarmrules.html。页面文案写「耗水/阶段」，不要写「潮湿值」。

完整示例（阿比盖尔一类多数值）：

<states><state><span class="stat-orb stat-health"><span class="stat-emoji">❤️</span></span><span class="stat-value"><b>150</b></span></state><state><span class="stat-orb stat-attack"><span class="stat-emoji">⚔️</span></span><span class="stat-value"><b>40</b></span></state></states>

单个示例（暗影仆人一类）：

<state><span class="stat-orb stat-health"><span class="stat-emoji">❤️</span></span><span class="stat-value"><b>1</b></span></state>
